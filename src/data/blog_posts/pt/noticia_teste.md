# Primeiro Teste de Comunicações do TejoOne

Hoje marcou um dia histórico para o projeto TejoOne. A nossa equipa de comunicações realizou com sucesso o primeiro teste completo do sistema de comunicações do CubeSat.

## Objetivos do Teste

Os principais objetivos deste teste eram:

- Verificar a funcionalidade do transceiver
- Testar a qualidade do sinal RF
- Validar os protocolos de comunicação
- Medir a potência de transmissão

## Resultados Obtidos

Os resultados foram extremamente positivos:

1. **Transceiver funcionou perfeitamente** - Conseguimos estabelecer comunicação bidirecional
2. **Sinal RF com excelente qualidade** - SNR acima dos valores esperados
3. **Protocolos validados** - Todos os comandos foram executados corretamente
4. **Potência dentro das especificações** - 2W conforme planeado

### Dados Técnicos

```
Frequência: 437.5 MHz
Potência: 2W
Modulação: GMSK
Taxa de dados: 9600 bps
```

## Próximos Passos

Com este teste bem-sucedido, avançamos agora para:

- Testes de alcance em campo aberto
- Integração com o sistema ADCS
- Testes de comunicação em ambiente simulado de órbita
