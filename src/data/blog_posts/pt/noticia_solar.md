# Primeiro Teste de Painéis Solares do TejoOne

O projeto TejoOne alcançou mais um marco importante: a realização do primeiro teste funcional dos painéis solares e do sistema de gestão de energia a bordo.

## Objetivos do Teste

Os principais objetivos foram:

- Verificar a eficiência de conversão dos painéis solares  
- Testar o sistema de regulação de carga das baterias  
- Medir o desempenho sob diferentes condições de iluminação  
- Validar a comunicação entre o BMS e o EPS

## Resultados Obtidos

Os resultados foram encorajadores:

1. **Eficiência média de 22%** — dentro das especificações de projeto  
2. **Regulação estável de tensão** — variação inferior a 2%  
3. **Carga completa em 3 horas de simulação solar**  
4. **Integração bem-sucedida com o sistema de telemetria**

### Dados Técnicos

```
Tensão nominal: 8.4 V
Corrente máxima: 2.1 A
Eficiência: 22%
Área total: 0.12 m²
```
